# Instruction Examples

[User manual](../user-manual.md)

Use your preferred language to describe your goal.
Give your agent clear instructions in your chosen harness, using the examples below as a guide.
The examples below are grouped into [setup](#setup), [research](#research), [administration](#administration-instructions), [manuscript writing](#writing-instructions) and [Lean formalization](#lean-instructions) instructions.
Adapt the wording to your actual question, files and scope.
