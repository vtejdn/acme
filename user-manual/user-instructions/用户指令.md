# 指令示例

[用户手册](../用户手册.md)

用自然语言描述你的目标。
以下示例分为[设置](#setup)、[研究](#research)和[管理](#管理指令)三类指令。
你可以根据实际问题、文件和工作范围调整措辞。

## <a id=setup></a>设置指令

这些示例用于准备工作区、登记作者身份和配置本地资源。
安装与登记的步骤顺序见手册的[设置](../用户手册.md#setup)。

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 把 [ACME](https://github.com/vtejdn/acme) 下载到目录 `D:\acme` | 确认目标目录适合安装，下载 ACME 框架文件，保留已有内容，并报告实际版本和后续设置事项。 |
| 安装 [Git](../git-repository.md#notion-git) | 确认是否已安装 Git；需要时安装，并报告可用版本和必要的后续设置。 |
| 告诉我如何连接 [GitHub](../git-repository.md#notion-github) | 说明登录、认证和连接远程仓库的步骤，并指出需要你完成的操作。 |
| 我已经登录 GitHub，进行连通测试 | 核对当前认证账号，以只读方式测试 GitHub 和目标仓库的可达性，并报告连接结果或具体错误。 |
| 把 [ACME](https://github.com/vtejdn/acme) [克隆](../用户手册.md#notion-clone)到 `D:\acme` | 确认 Git、访问权限和目标目录可用，克隆 ACME 仓库及其版本历史，并报告实际分支、版本和后续初始化事项。 |
| 将我登记为 Ali | 登记作者键 Ali；若当前目录是 Git 工作副本，同时将其关联到 Ali，并保留已有协作者身份。 |
| 设置 Git，连接到我的仓库 <https://github.com/alice/acme>。 | 配置本项目的 Git 和指定远端，核对真实提交身份并测试访问，保留已有提交和不相关设置。 |
| 克隆我的合作者仓库 <https://github.com/alice/acme>，并将我登记为 Bob | 克隆共享仓库，按实际身份登记作者键 Bob，并将新克隆的 Git 工作副本关联到 Bob；保留已有作者和研究材料，说明 Git 提交身份的设置情况。 |

## <a id=research></a>研究指令

这些示例用于处理文献和进行数学探索。

### 查找、登记或审计文献

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 查看本地文献 abc26，入库并审计 | 核对 abc26 的作品、版次和本地原件，补齐书目及文件登记。原文有目录时，整理为可检索的文献目录。审计其数学内容，记录实际检查范围、结论和未解决问题。 |
| 审计文献 abc26 的定理 1.7 | 定位原文定理 1.7，核查完整陈述、假设、证明及必要依赖的适用性，记录审计结论、未检部分和具体缺口。 |
| 搜索 On the construction of S，尝试入库并审计 | 识别作品与版次，检索已有记录并尝试获取原文；登记书目和实际获取结果。原文有目录时，整理为可检索的文献目录。审计取得的内容，明确不可用部分。 |
| 这个定义在相关文献如何使用的？ | 查阅已有定义记录和相关原文，比较对象、假设、符号及使用场景，给出准确引用，并区分来源定义与本地改写或推广。 |

### <a id="start-or-continue-research"></a>开始或继续[任务](../用户手册.md#material-task)

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 把 abc26 中的猜想 1.3 设为 W 系任务 | 核对猜想 1.3 的原文、假设和范围，先查找已有同题 Task；需要新建时使用 [W 系](../用户手册.md#notion-research-line-letter)，写明来源、精确问题和完成标准。 |
| 以如果 P，则 Q 设置一个任务，F 系 | 明确 P、Q 的对象、假设和量词，以“P 蕴含 Q”为完整目标建立 F 系 Task，并明确完成标准。 |
| 将命题 P 从有限维情形推广到无限维情形，建立新任务 | 核对原命题，明确新对象、假设和拟证明的结论，建立 Task，并将原命题保留为应涵盖的特例。 |
| 设置任务：找到在 P 情形下的一般公式，能覆盖 abc26 中公式 (1) | 核对原公式的假设和记号，明确 P 情形及一般公式的适用范围；建立 Task，把公式的正确推导及其如何涵盖原公式写入完成标准。 |
| 开始推进任务 F0001，直到周用量剩余 5%，整理进展后暂停 | 核对任务现状和执行条件，确认能读取适用周用量后推进研究；监测剩余量，按 5% 阈值停止推进，整理成果、未决问题和续研位置后暂停。 |
| 继续推进任务 F0001 | 读取当前目标、策略、已有成果和停止条件，在本次授权及仍有效的限制内恢复推进；遇到尚未解除的停止条件时，说明阻碍继续的具体原因。 |

### 共同目标

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 先查看协作者的路线，再为我的 Task F0001 选择有用的方法。 | 阅读相关路线、可复用结果和有启发的失败，在 F0001 的参与范围与现有执行条件内选择或调整自己的 Strategy。不同路线可以减少重复工作；有意进行独立验证、复现和交叉核查仍然适当。 |
| 以此问题建立联合任务，并关联到任务 F0001 | 核对共同问题、假设、范围和完成标准，建立或复用适当的联合 Task；将你的 F0001 关联到实际采纳的共同契约版本，明确参与范围及个人完成标准，并保留现有执行条件。建立关联本身不启动研究。 |

## 管理指令

这些示例用于 Git 操作、环境设置和日常维护。

### 提交与推送

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| [提交](../用户手册.md#notion-commit)，[推送](../用户手册.md#notion-push) | 确定本次交付范围，保留其他暂存工作，核对真实身份、分支和目标远端；确认连接后创建提交并推送，报告提交范围和远端结果。 |
| 提交、推送 F0001 对应的手稿目录下改动 | 定位 F0001 对应的手稿项目，仅提交指定目录内应纳入 Git 的改动，保留其他工作；确认身份、目标和连接后推送，并报告实际范围。 |
| 提交工作区全部改动 | 确认工作区全部改动及作者归属，将应纳入 Git 的内容创建为本地提交，保留忽略规则排除的文件，并报告提交范围和剩余改动。 |
| 提交推送，不做任何检查 | 不运行内容审查、格式检查、测试或额外扫描；仅进行完成 Git 交付所必需的范围、身份、目标与连接确认，完成指定提交和推送并报告结果。 |

### 拉取与合并

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| [拉取](../用户手册.md#notion-pull)远端最新改动，与[本地分支](../用户手册.md#notion-git-branch)[合并](../用户手册.md#notion-merge) | 核对当前分支及对应远端，保留本地工作，获取并合并远端更新，报告结果；遇到涉及数学含义的冲突时，说明具体差异和处理建议。 |

### 环境设置

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 创建目录联接（Junction），将 [mathematics/literature/pdf](../../mathematics/literature/pdf) 指向 `D:\MyLiterature` | 核对入口路径和目标目录，保留已有文献，将项目本地文献入口设为指向指定目录的 Junction，并确认文献文件不纳入 Git。 |
| 把本项目使用的`〈harness 名称〉`的默认[上下文长度](../用户手册.md#notion-context-length)设为 512k | 查明该 [harness](../agent-harness.md) 的项目级配置，确认模型和运行环境支持该长度后修改本项目默认值，并说明生效方式，以及实际生效情况是否已经验证；不支持时报告实际限制。 |
| 设置我的默认任务停止条件：周用量剩余 5% 时暂停 | 记录为你的个人默认执行偏好，在没有更具体设置时适用；保留既有 Task 的有效条件，并说明如何读取适用周用量。 |

### 日常维护

| 指令示例 | Agent 的预期行动 |
| --- | --- |
| 暂缓框架升级，继续当前工作 | 保留已安装版本，继续已授权的任务；提醒本身不构成升级授权。 |
| 关闭本仓库的框架版本自动检查 | 关闭本仓库每日的版本元数据检查，保留现有框架和研究工作。 |
| 启用本仓库的框架版本自动检查 | 启用本仓库每日检查；后续升级仍须你的明确要求。 |
| 现在重新检查官方框架版本 | 进行一次新的、有时限的版本检查，报告已安装版本及确认可用的版本或无法确认的结果，并保留此前实际提醒。 |
| 将本仓库升级到刚刚确认的官方框架版本 | 明确所选版本、受影响的本地框架文件及实际材料迁移，保留已有研究与有效 Task 条件，完成这次明确授权的升级。 |
| 分析 `.tmp` 下的文件，确认可以删除后删除 | 核实文件用途和使用状态，先保留尚未存入正式材料的必要内容，再删除已确认可弃且未被其他活跃会话使用的临时文件。 |
