# Git、Git リポジトリ、GitHub

## <a id="notion-git"></a>Git

Git は、自分のコンピューターで動作する分散型バージョン管理システムです。
ファイルの変更を記録し、以前のバージョンの確認や復元、複数の開発ラインでの並行作業を可能にします。
タイムマシン付きの保存システムに例えると、一つひとつの保存がコミットに当たり、任意の保存時点に戻ることができます。
Git はローカルで動作し、ネットワーク接続を必要としません。

主な用語は次のとおりです。

- **コミット（Commit）**は、メッセージと一意のハッシュ値を持つ、記録済みのスナップショットです。
- **ブランチ（Branch）**は、`main` や `feature-x` などの並行する開発ラインです。
- **マージ（Merge）**は、あるブランチの変更を別のブランチに統合することです。
- **作業ツリー（Working tree）**は、現在表示し、編集しているファイルです。
- **ステージング領域（Staging area）**は、次のコミットに含める変更を選んでおく場所です。

よく使うコマンドは次のとおりです。

```bash
git status                         # 変更の状態を表示する
git diff                           # 実際の差分を表示する
git add FILE                       # 変更をステージする
git commit -m "Describe the change" # スナップショットを記録する
git log                            # 履歴を表示する
git branch                         # ブランチを一覧表示する
```

## <a id="notion-git-repository"></a>Git リポジトリ

Git リポジトリは、プロジェクトのディレクトリと、隠しディレクトリである `.git` で構成されます。
`.git` ディレクトリには、コミットの全履歴、ブランチ、タグ、設定が保存されます。
編集するプロジェクトファイルが作業ツリーを構成し、リポジトリはそれらのバージョン履歴を保持します。

リポジトリは自分のコンピューター内だけに置くことも、一つ以上のリモートリポジトリに接続することもできます。
`git init` で作成し、`git clone` でコピーし、`git fetch`、`git pull`、`git push` などのコマンドで同期します。
`origin` は、主なリモートリポジトリに慣例的に使われる名前です。

Git リポジトリは、単にファイルを集めたフォルダーよりも多くの情報を持ちます。
ファイルが現在の状態に至るまでの過程を、確認可能な履歴として完全に記録します。

## <a id="notion-github"></a>GitHub

GitHub は、Git リポジトリのホスティングと共同作業のためのクラウドプラットフォームです。
Microsoft が所有しており、Git とは別のサービスです。
GitHub は、リモートストレージ、Web インターフェース、プルリクエスト、Issue、ディスカッション、権限管理、GitHub Actions による自動化を提供します。

Git リポジトリは、GitLab、Gitee、企業のサーバー、ローカルディスクにも置くことができます。
GitHub は広く使われるホスティングと共同作業の基盤ですが、Git の利用に必須ではありません。

### <a id="connect-github"></a>ローカルプロジェクトを GitHub に接続する

コンピューター上のプロジェクトフォルダーを初めて GitHub に接続するときは、次の手順に従ってください。
プロジェクトフォルダーには編集するファイルを保存し、GitHub リポジトリはプロジェクトのオンラインでの保存先となります。
この手順では SSH を使い、コンピューター上の鍵で Git から GitHub に認証します。

1. **ブラウザーで GitHub にサインインします。**

   [GitHub](https://github.com/) を開き、**Sign in** を選択します。
   アカウントを作成する場合は **Sign up** を選び、手順に従ってメールアドレスを確認します。
   後で SSH 鍵を追加するときも、このアカウントを使います。
   共同研究者の既存リポジトリに参加する場合は、まず[共同研究への参加手順](../ユーザーマニュアル.md#setup-collaboration)に従って招待を承認し、アクセス権を確認してください。

2. **プロジェクト用の空のリポジトリを作成します。**

   プロジェクトに GitHub リポジトリがある場合は、共同研究者のリポジトリに参加する場合も含め、手順 3 に進んでください。
   それ以外の場合は、[リポジトリの新規作成ページ](https://github.com/new)を開きます。

   1. **Owner** で自分の GitHub アカウントを選択します。
   2. **Repository name** に `my-math-project` などの名前を入力します。
   3. **Visibility** でリポジトリを閲覧できる範囲を選びます。
      プロジェクトの公開範囲を制限する場合は **Private** を選択します。
   4. README の追加を無効にし、`.gitignore` とライセンスの選択肢を **None** にします。
      これで、既存のプロジェクト用に空のリポジトリを作成できます。
   5. **Create repository** を選択します。

   [GitHub のリポジトリ作成ガイド](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository)を参照してください。

3. **エージェントに Git の準備を依頼します。**

   ローカルプロジェクトがある場合は、ACME をインストールして利用しているフォルダーなど、そのプロジェクトフォルダーをエージェント実行環境で開きます。
   共同研究者の既存リポジトリに参加する場合は、コンピューター上に新しい空のローカルフォルダーを作成し、そのフォルダーをエージェント実行環境で開きます。
   エージェントに [Git のインストール指示](../user-instructions/指示例.md#install-git)を送ります。
   Git の準備ができたことをエージェントが確認したら、次に進みます。

4. **GitHub アカウントの SSH アクセスを設定します。**

   SSH 鍵は二つの部分から成ります。
   公開鍵を GitHub に追加し、秘密鍵は Git を実行するコンピューターに保持します。
   エージェントに次の依頼を送ります。

   > 新しい GitHub アカウントの SSH 設定を手伝い、追加する公開鍵を表示してください。

   ターミナルで鍵のパスフレーズを求められた場合は、ターミナルに入力してください。
   [GitHub の SSH 鍵の作成と SSH エージェントへの追加ガイド](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent)を参照してください。

   ブラウザーで、自分の GitHub アカウントに公開鍵を追加します。

   1. エージェントが表示した公開鍵のテキストを、一行全体を含めてコピーします。
      公開鍵のファイル名は `.pub` で終わります。
   2. GitHub でプロフィール画像をクリックし、**Settings** を選びます。
      サイドバーで **SSH and GPG keys** を選択し、**New SSH key** または **Add SSH key** をクリックします。
   3. **Title** に `Personal laptop` など、自分で識別しやすい名前を入力します。
      **Key type** では **Authentication Key** を選びます。
   4. **Key** に公開鍵を貼り付けて **Add SSH key** をクリックし、求められた場合はアカウントを確認します。

   [GitHub の公開鍵追加手順](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account)を参照してください。

   鍵を追加したら、エージェントに [SSH 接続テストの指示](../user-instructions/指示例.md#test-github-ssh)を送ります。
   GitHub が自分のアカウントを認識したことをエージェントが確認したら、次に進みます。

5. **プロジェクトを GitHub に接続します。**

   ローカルプロジェクトがある場合は、[接続の指示](../user-instructions/指示例.md#connect-github)を使い、例のアドレスを接続先リポジトリのアドレスに置き換えます。
   共同研究者の既存リポジトリに参加する場合は、[クローンの指示](../user-instructions/指示例.md#clone-repo)を使い、手順 3 で準備した空のフォルダーにクローンすることを明示してエージェントに依頼します。
   クローン後は、[共同研究への参加手順](../ユーザーマニュアル.md#setup-collaboration)に従って、必要な著者登録と Git のコミットに使う識別情報の設定を行います。
