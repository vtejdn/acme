## エージェント実行環境とは

エージェント実行環境（agent harness）は、大規模言語モデルにタスクを与え、ファイルやほかのツールを使って作業させるためのソフトウェアです。
モデルがエンジンに当たるのに対し、実行環境はシャーシ、変速機、ハンドルに当たります。
実行環境がツール、コンテキスト、権限、実行ループを制御するため、同じモデルでも環境によって動作が大きく異なることがあります。

一般的な実行環境は、次の機能を提供します。

- **エージェントの実行ループ**：タスクの把握、計画、ツールの呼び出し、結果の確認、計画の修正を繰り返し、完了したら停止します。
- **ツール**：ファイルの読み書き、ターミナルコマンド、検索、ブラウザー操作、Git、MCP やプラグインとの連携。
- **コンテキスト管理**：会話履歴の削減、メモリー、コードベースの検索、サブエージェント。
- **権限と安全性**：承認の確認、サンドボックス、読み取り専用または書き込み可能な範囲、ネットワーク制御。
- **観測と評価**：ログ、実行トレース、費用の追跡、ベンチマーク、回帰テスト。

以下の表は、2026 年 11 月 16 日に確認した主なモデル系列と利用方法をまとめたものです。
利用できるモデルは、アプリのバージョン、プラン、地域、プロバイダーの認証情報、組織の設定によって異なります。
最新の一覧は、リンク先の公式モデルガイドを参照してください。
モデルに対応していても、そのサービスを利用する権利が含まれるとは限りません。
実行環境によっては、自分の API キー、プロバイダーの契約、またはローカルモデルサーバーが必要です。

Open Math OS は数学研究用のワークスペースで、プロジェクトごとのクラウドマシン、共有ファイルと会話、Ultramath によるエージェントの並列作業を提供します。

## ACME を使い始める

1. 公式ガイドに従ってアプリや IDE をインストールするか、クラウド実行環境にログインします。
   必要に応じてエージェント拡張機能をインストールしてください。
2. ツールの要件に応じてログインまたはモデルプロバイダーの設定を行い、モデルを選択します。
3. アプリや IDE で ACME プロジェクトのフォルダーを開くか、プロジェクトのファイルをクラウドワークスペースにアップロードします。
4. [ユーザーマニュアルの設定手順](../ユーザーマニュアル.md#setup)と[セットアップの指示例](../user-instructions/指示例.md#setup)に従って設定を続けてください。
