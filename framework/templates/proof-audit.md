# Proof Audit

Before creating or retaining content with this template, apply the [common content decision](../rules/records.md#substantive-material-retention), reuse an adequate responsible home, and then follow this kind's actual registration, reproduction, source or review obligations.
A template does not justify a process-only record.

## Inline Audit Template

Use this structure in a numbered fixed R material for every formal project-review account, whether agent self-review, independent review or a genuinely unknown older/source relationship.
Partial, negative, unresolved and unadopted findings also belong to R; several findings may share an appropriate R.
The optional `material.py create --kind R --line F --file review.md` writer uses the real author and supplied evidence.
Its new fixed family uses the actual [`material_next` namespace](../material-format.md#material-family-allocation-state), so retirement cannot make that number available again.
The reviewer judges actual coverage and applicability under the [common responsibility](../rules/workflow.md#agent-and-tool-responsibilities).
Expand only fields relevant to the argument while preserving necessary scope/evidence.
Follow the [review arrangements and disclosure rules](../rules/proof-audits.md#review-arrangements); no individual agent identity is required.
This template records the review; its field order does not prescribe when to read previous assessments.

Replace the illustrative Claim rows with every actual required input.
For Task completion, bind the exact contract and each support/dependency.
Paths above assume an R under mathematics/audits/reviews/.
Include only the scope really reviewed; an unperformed check must not be implied by a template row.

Replace the illustrative relationship with the actual agent arrangement; use unknown only for a genuinely unestablished older/source relationship.
Each newly authored or substantively revised finding needs its own explicit matching relationship row, and every finding actually selected for a genuinely new C/T acceptance needs that row as well as its exact required bindings.
Omission is not an `unknown` declaration; unchanged older findings in the same file remain readable at their actual scope without a backfill requirement.
Classify each finding, not its consumer; complementary applicable findings preserve their actual separate relationships and scopes.
An independent reviewing agent must be outside substantive proof development and receive no inherited mathematical discussion, summary or prior verdict; direct fixed statements, proofs and necessary dependencies are legitimate inputs.
If an independently identified gap is repaired, arrange independent review again; a substantive repair contributor cannot independently review that repair.
Human authorship or suggestions do not constitute a framework review, and no agent/model/session registry or isolation certificate is required.
