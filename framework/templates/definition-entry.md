# Definition Entry

## Entry Template

The following is an unregistered template, not a definition, claim or allocated identifier.
Use a descriptive stable anchor for an actual group or entry.
Omit optional fields when they add no information, and link existing precise records instead of repeating them.

```markdown
## <Concept group>

- General definition: <standard or descriptive name>.
- Exact home: <stable link to complete U/C/L content: objects, parameters,
  quantifiers, construction or condition, domains and conventions>.
- Terminology and symbols: <established aliases, source notation and normalizations;
  distinguish actual mathematical variants from mere letter substitutions>.
- Source/convention: <source audit link with version and exact locator;
  identify a local convention or departure only when applicable>.
- Consumer navigation: <links derived from actual forward references;
  label statement, identified proof version, or discussion>.
- Optional citation candidates: <existing citation key, locator and purpose>.
```
