# Upgrade from 0.9.7 to 0.9.8

The target is `0.9.8`.
The preceding official tag `0.9.7` identifies [commit cc1bb103ac2b054a1b6a8a9c31e25e395faa4c24](https://github.com/vtejdn/acme/commit/cc1bb103ac2b054a1b6a8a9c31e25e395faa4c24).
This PATCH release applies to existing `0.9.7` installations.

## Changes

- Centralize the [repository writing language rule](../rules/organization.md#repository-writing-language) in `framework/rules/organization.md` and link to it from `AGENTS.md`.
  Use English when writing or substantively revising repository prose, except in non-English editions of the user manual and instruction examples.
  Apply the rule to Git-ignored local notes and new manuscript review comments, while preserving exact source evidence.
  Use the adopted language of an existing manuscript or locally maintained publication page to guide reading, review and preservation of its prose.
  Preserve the exact project display name and abbreviation in the README heading, escaping Markdown where needed for faithful rendering.
  Preserve the exact attribution name in the `LICENSE` project notice and use English for the surrounding explanatory prose.
- Align the maintenance worklist in `framework/rules/records.md` and the scope and recording of writing choices in `framework/rules/preferences.md` with the shared rule.
- Ship this note at `framework/upgrade/0.9.8.md`, advance `framework/version.json`, and update the current-version sentence in each user manual.

Use ordinary synchronization and bounded local merges to adopt this release.
