# Upgrade from 0.2.0 to 0.3.0

The preceding published version is `0.2.0`, whose official tag fixes commit `34520db3d54fbb288435213d3e6ca2169a7575fd`; the target is `0.3.0`.
The public export interface, version metadata, template locations and output home change incompatibly during 0.x development.
Use the [installed-framework upgrade procedure](../versioning.md#upgrading-an-installed-framework).

## What changed

- **Versioning and installation.** `framework/version.json` replaces `framework/export-manifest.json` and contains only `framework_version`.
  `framework/exporting.md`, `framework/export-templates/`, `scripts/export-framework.py` and `scripts/acme/framework/export.py` are removed; the version helper and installation entrances use ordinary fixed-source installation and upgrade.
- **Templates and document workspaces.** The eight mathematical examples move from the top level of `framework/templates/` to `framework/templates/mathematics/`, keeping their filenames.
  `framework/templates/execution-run.md` moves to `framework/templates/execution/execution-run.md`.
  Document-local `mathematics/manuscripts/.gitignore` and `mathematics/presentations/.gitignore` replace root suffix lists.
- **Personal setup.** Repository and identity helpers allow an absent/null name without Git, preserving chosen names and requiring the existing name/binding checks when Git-managed research writing or delivery is selected.
- **Computations and receiving.** The current output home becomes `mathematics/computations/outputs/` beside `programs/`; path, import/intake, rules, templates and entrances follow it.
  Intake distinguishes tracked source targets from absent source-only references, and U reception applies original acquisition with truthful failure reporting.
  Literature, writing and source-unit guidance allow adequate precise U or C/L inspection evidence for first-work citation where the actual source conditions apply.
- **Human documents.** Shipped guides remain under `user-manual/`, including `user-manual/Manual de usuario.md` and `user-manual/user-instructions/Ejemplos de instrucciones.md`; necessary output-path literals also change.
