# Upgrade from 0.3.0 to 0.4.0

The preceding published version is `0.3.0` at [official commit 6c51f560f84cc9d3d7b0a791eaf6f9d38b3da76b](https://github.com/vtejdn/acme/commit/6c51f560f84cc9d3d7b0a791eaf6f9d38b3da76b); the target is `0.4.0`.
Physical C/T input declarations and selected-status output change incompatibly during 0.x development, without an obsolete-format fallback.
Use the [installed-framework upgrade procedure](../versioning.md#upgrading-an-installed-framework).

## What changed

- **Material inputs and status.** The document, review, writer-facing CLI, discovery and index readers in `scripts/acme/materials/` use ordinary Inputs for a local C/T/R/L revision's acquired receiving inputs, independently of its Current selector.
  Selected-status output uses `status` with `selected_decision`, replacing external-material `source_status`.
  Original correspondence applies only to the actually acquired scope; a source header transfers no review coverage to local revisions.
- **Selected references and publication.** `scripts/acme/intake/acquire.py`, `scripts/acme/materials/importing.py`, `validation.py` and `scripts/acme/core/links.py` align selected-tree facts, public/private boundaries, logical literature navigation, ordinary directories and non-Markdown fragments.
  Selected pending files can supply required parent directories; occupied directory positions refuse before allocation, and failures after issuance preserve allocation bounds.
  Canonical receiving Markdown and exact prepared updates retain source filenames, fixed evidence and necessary publication protections.
- **Guidance and manuals.** The action guide, material format, record/intake/workflow rules and `scripts/readme.md` follow these contracts.
  The six English, Chinese, French, German, Japanese and Spanish manuals under `user-manual/` change their current-version sentence to `0.4.0`; their bodies and translations are outside this release's changes.

No shipped path is removed or moved.
