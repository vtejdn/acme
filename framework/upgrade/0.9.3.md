## Installation target and source retrieval

Before retrieving content or creating a directory, determine the actual authorized purpose and final project root from the human request, workspace and target contents.
Browsing the official repository alone authorizes no installation, project creation or target-directory change.
The framework's installation and upgrade actions use selected official version or fixed-commit files, a source snapshot or sufficient available contents; they no longer recommend cloning the official ACME repository to establish a research project.
When asked to install ACME into the current existing project, integrate the selected framework files into that project's root by default, preserving its Git repository, remote, content and necessary entrances.
The official name does not make a new `acme/` child checkout the final installation target.
Apply the same purpose-based choice without Git and when the actual Git worktree uses a pointer file, without a compulsory detection command.

An existing ACME installation uses its normal upgrade action when an upgrade is authorized.
New research projects also use file installation; when Git is wanted, use or establish the human project's own repository within actual setup authority instead of adopting official history by default.
Joining an existing research collaboration retains cloning that actual project and its history.
Framework development and actual explicit clone instructions retain their ordinary scope; withdrawing an installation recommendation neither bans the tool nor creates an exception-approval procedure.
Resolve a concrete decisive conflict rather than silently redirecting the installation to another directory.

Keep source acquisition distinct from final installation, including any outer directory produced by unpacking a snapshot.
When temporary local source is necessary, use a creator-owned child of the project's root `.tmp/` under the existing storage and cleanup rules, explicitly choosing the download or extraction destination.
The agent may choose Git retrieval for an actual comparison, source inspection or maintenance need under existing tool responsibilities, without making cloning an installation prerequisite.
Reuse adequate available sources when sufficient; no Git executable is mandatory for file installation.
Carry no source `.git`, refs or official commit history through file installation; preserve an existing project's own Git history and remote.
Merge affected project README, AGENTS, ignore rules, complete license and other necessary files at their actual scope, retaining local content, identities and configuration.
Actual Git delivery follows its existing authority, history and outgoing-chain checks; local installation requires neither a preliminary commit nor a project-remote preflight.

## Existing installations and checks

This clarification requires no retrospective scan, reinstallation or automatic movement or deletion of existing nested repositories.
Handle an actual misplaced copy under its concrete assignment and the existing content, Git and cleanup boundaries.
An ordinary upgrade merges the affected entrance and manual changes while preserving the project's actual root and Git relationships.

For an actual installation, verify the version metadata, necessary framework files and working entrances at the final project root, along with preservation of existing content and Git history and the exclusion of source Git metadata and history from this file operation.
A successful source clone or version file in a temporary or unintended nested checkout does not establish installation into the requested project.
Check the changed framework wording, direct entrances, actual human-document distribution coverage and destination synchronization, plus necessary mechanical versions and links, without assigning manual-body or translation review to development acceptance.
No whole-workspace nested-repository scan or new automated agent test platform is required.
Keep collaboration and actual explicit clone instructions effective without treating every occurrence of the word clone as an installation recommendation.
