# Upgrade from 0.6.0 to 0.7.0

The preceding official version is `0.6.0`, whose tag fixes commit `1a828f60585f305896e7b91adbaef9c5ea953be0`; the target is `0.7.0`.
The machine-local literature account and required notification precondition are incompatible changes under the 0.x version rule.
Use the [installed-framework upgrade procedure](../versioning.md#upgrading-an-installed-framework).

## What changed

- **Local literature account.** `mathematics/literature/registry.md` leaves common distribution and becomes ignored persistent local acquisition/holding state at the same logical path.
  `.gitignore`, literature entrances, rules and the path, Git-view, discovery, runtime, CLI and intake/source helpers keep shared facts independent of local holdings.
  U show removes `source_holding` and automatic holding-enrichment notices; explicit local source operations use current local facts without Git-view fallback.
  Mathematical digests remain prohibited; an existing literature fingerprint remains only a local accidental-damage baseline in this release.
- **Transfer and review.** The intake, record, ledger, Claim and review rules, material format and affected Claim/proof-audit/research-operation/source-unit templates clarify complete selected Task/manuscript collection, concrete duplicate comparison and truthful review arrangements.
  No relationship enum, R-binding schema or C/T adoption interface changes.
- **Runtime ownership.** Organization, execution, computation, writing and action guidance place continuing machine choices in local `execution/runtime/readme.md`, separate from E and optional `.venv/readme.md`.
  Public host-specific prose and links do not become shared runtime configuration.
- **Notification writing.** `scripts/acme/framework/version.py`, `scripts/acme/core/repository.py`, versioning and interface guidance require an explicitly observed notification premise and preserve concurrent cache queries.
- **Human documents.** The six English, Chinese, French, German, Japanese and Spanish manuals under `user-manual/` change the local-registry lookup link and version sentence; their other prose is outside this release's changes.

`mathematics/literature/registry.md` is the only removed common-distribution path; its existing local bytes must be retained during this transition.
