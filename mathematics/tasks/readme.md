# Tasks

The [current index](index.md) derives exact Task contracts, selected lifecycle decisions and continuation links.
Author Tasks with the [Task template](../../framework/templates/task.md) under the [framework rules](../../framework/readme.md); this empty entrance assigns no research objective or execution authority.
An optional [joint Task](../../framework/rules/tasks.md#joint-tasks-and-participation) owns a shared contract without E or direct S; individual Tasks adopt exact common contracts and retain their own execution conditions and strategies.
Participation navigation derives from the individuals' declarations, without a separate member list or common completion inferred from child counts.
