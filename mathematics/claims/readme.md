# Claims

Before direct C creation or registration, apply the [common content decision](../../framework/rules/records.md#substantive-material-retention) to the statement, argument and existing homes.
Register an actual conjecture/obligation with its unresolved status when needed; routine setup does not warrant an empty Claim.
Follow the [kind-specific rules](../../framework/rules/claims.md#claim-registration).

Use one numbered main-material family per formal Claim, with local addresses such as `Author_C_F0001_v1.md` and receiving addresses such as `author1_repo1_C_F0001_v1.md`.
The external numbers identify the receiving registration; actual original human and repository facts remain in the external records, minimal source header and intake provenance.
Keep the descriptive title in the document.

See the [index](index.md), [material format](../../framework/material-format.md) and [Claim template](../../framework/templates/claim.md).
An explicit selected decision owns the current assessment and its exact statement, argument and review; the index is navigation only.
No sample Claim is created by export.
